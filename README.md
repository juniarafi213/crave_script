# Crave Build Scripts

Collection of custom ROM build scripts for Crave.io cloud build platform.

## LineageOS 23.2 (Android 16) for Sony Tama

### Supported Devices:
- Sony Xperia XZ2 (`akari`)
- Sony Xperia XZ2 Premium (`aurora`)
- Sony Xperia XZ3 (`akatsuki`)

### Run on Crave:
```bash
crave run --no-patch -- "curl -fsSL https://raw.githubusercontent.com/juniarafi213/crave_script/main/lineage.sh | bash -s -- --akari"
```
